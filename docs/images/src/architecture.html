How Jevstral answers a question

One forward pass from document to probabilities. The model reads the row once and never generates text.

Input

A document and a typed question

I was charged twice for order 1182. Please refund one of the charges.
Which team?
· billing
· shipping
· returns

Token row

One row for each question

<s> <state> I was charged… <q> Which team? billing </opt> shipping </opt> returns </opt> <decide>

Ministral 3 8B decoder

34 layers · base weights frozen

Causal self-attentionEach token reads earlier tokens only
q k v o + LoRA
MLP (SwiGLU)4,096 → 14,336 → 4,096
gate up down + LoRA
State cacheThe document is read once for all questions of a request

Pointer head

Reads the orange positions

scorei =
q(hdecide) · k(hopt i)
/ √256

q, k: 4,096 → 256
The same k scores every option, so any number of options works.

Probabilities

softmax(score / T)
T = 2.04 after calibration

The temperature T makes the probabilities match how often the model is correct.
